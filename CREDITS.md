# Credits

Every asset distributed in this repository, with its source and licence.

**A row is added when the asset is added.** Provenance reconstructed later
usually cannot be, and an asset whose licence cannot be shown has to be
deleted. CI refuses a build where a file under `assets/` has no row here.

"Changes made" is not optional for CC BY and CC BY-SA — both require derivative
works to be marked as modified. Write "none" if the file is unmodified.

## Sound

No audio files. Every cue and music bed is synthesised in the browser with Web
Audio by the code in `audio/`, written for this project. If a rendered sound
file is ever added, it goes under `assets/` with a row in the table above, and
the code that generated it is committed beside it.

## Code

Third-party code and its licences are declared in the dependency manifests, not
here.
